# 官网对话引用

用户想引用的是他自己账号里的官网网页版对话（DeepSeek / MiniMax / ChatGPT），不是本仓库、也不是本地文件。

## 怎么取

1. 先用 `official_chat_list` 找会话。站点用 `site` 指定：`deepseek`（缺省）、`minimax`、`chatgpt`。用户没说站点就先问一句，别猜；目录里没有要找的会话时，可以带 `refresh: true` 再取一次当刻目录。
2. 从返回的条目里选会话，把 **id** 原样交给 `official_chat_read`（`site` 要与目录那次一致），取回分段正文。
3. 引用时说明内容来自哪个站点、哪条会话；正文不完整时如实说明，不要补齐或改写。

## 边界（如实转述，不要装作没有）

- 正文来自 dsh-xlink 壳打开的官网网页版窗口，用的是用户自己的登录态。登录失效时读取会失败，把失败原因转述给用户，不要自己重新登录或猜账号。
- 这里没有工作台的 `@` 选择菜单：用户必须说清站点和会话（或让模型先列目录），不会自动挂上引用标记。
- 目录只取站点最近若干条会话（条数看返回里的「站点原始总数」），不是全部历史。
- 正文可能不完整：返回里的「省略」「未支持」要如实转述；很长时会被截断，要说明「已截断，原文更长」。
- 会话 id 只能来自当前工作台、当前账号的 `official_chat_list` 返回；换账号或重启工作台后须重新列目录。读取失败就报失败原因，不要用别的会话顶替。
