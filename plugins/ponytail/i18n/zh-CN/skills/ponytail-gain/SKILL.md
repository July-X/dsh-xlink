# Ponytail Gain

被调用时展示这块记分板。一次性：**不要**改档位、写标志文件或持久化任何东西。

下面这些数字是 Ponytail 5 公布的 agentic 基准：无头 Claude Code（Opus 5.5，默认 effort）
跑 39 个任务（真实 FastAPI + React 仓库里的功能工单、bug 修复、安全与隐私用例、小应用），
每个任务 5 轮，对照组是同一个 agent 不带这个技能。其中 18 个任务藏了正确性与安全的
隐藏检查。每个数字是各任务中位数的几何平均。**它们是实测的，不是从当前仓库算出来的。**
出处：`benchmarks/results/2026-10-07-agentic.md` 与 README。

## 诚实边界

这些是基准平均值，不是这个仓库的实测值。**绝不**打印按仓库算出来的节省数字
（「你在这里省了 X 行 / X token」）：没构建出来的那一版压根没被写过，
所以真实仓库里没有可减的基线。真正按仓库算得出的数字只有 `/ponytail-debt`
（一份数过条的台账），这张卡片指向它，而不是自己编一个。
