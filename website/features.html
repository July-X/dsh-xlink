01 / MODELS选择适合当前任务的模型

模型由你选择。

在工作台配置模型提供商，按任务需要选择模型。DeepSeek、MiniMax、智谱及其他已配置的提供商，都可以在同一工作台里使用。

内置 OpenAI-OAuth 插件默认关闭，启用后可登录 ChatGPT；该插件仍属实验性功能，可用模型与额度以对应账户及提供商为准。

DeepSeek 01MiniMax 02OpenAI 03智谱 GLM 04模型和提供商取决于工作台配置。
02 / REFERENCES让已有上下文继续发挥作用

不止一个会话，
也不止一个来源。

在当前提问中选择多条会话引用，把不同讨论放在一起。启用内置的官网对话引用插件后，还可以引用 DeepSeek、MiniMax 和 ChatGPT 的网页会话。

在壳内登录对应官网后，输入 @DeepSeek/、@MiniMax/ 或 @ChatGPT/，选择最近会话。选中时保存一份固定的文字快照，供本次提问使用。

03 / TWO KERNELS一个窗口，两个内核

DSH 与 MiniMax，
各跑各的。

在设置里开启 MiniMax 体验后，概览页与内核版本页出现内核切换器。MiniMax Code 从官方 npm 版本安装，用自己的实例、端口和浏览器档案启动工作台，与 dsh 互不干扰。

两个内核可以同时运行、各自启停。公共页面只有一份骨架，切换时只换数据与少量字段；插件、技能与记忆按各自协议接入，Ponytail 也能在 MiniMax 侧启用。

MiniMax 是实验功能，默认关闭，当前支持 0.1.7。真实模型、浏览器能力与安装包验收仍在进行；范围与最新结论以接入计划为准。

04 / DESKTOP给工作台一个安稳的家

把日常管理，
收进一个窗口。

安装、切换官方 dsh 与 MiniMax 内核，管理插件和技能。插件安装前可以先运行兼容性预检，遇到问题也有诊断与环境恢复入口。

关闭窗口后，应用可以继续在后台运行；从托盘或菜单栏回到工作台。深色、浅色和跟随系统三种外观可选。

05 / INSIGHT & MEMORY用量有记录，约定有地方放

看得见用量，
记得住约定。

查看本地内核的模型用量，以及已配置提供商可查询的套餐额度。也可以显式选择读取本机 Codex 或 MiniMax Desktop 的用量，来源分开统计。

本地记忆可按需启用，保存项目约定、工作交接和经验。使用远端模型时，注入的记忆会成为模型输入的一部分。
