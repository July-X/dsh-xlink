# 公共记忆池：每内核启用、来源审核、自动引用

2026-11-09 本地开发，基于 main `ce62fc3f`。尚未发布，Rust 编译及 Windows / Intel macOS 原生验收未完成。

## 用户操作

1. 记忆页只选择 DSH / MiniMax 哪些内核启用记忆模块。首次启用展示当前来源实例和共享范围，由用户确认。原范围关闭后重开不重复确认；更换实例、profile 或增加来源时重新确认。
2. 自动提取与会话提出的内容进入「待审核」，标明来源内核和来源会话。审核通过才进入公共记忆池；手动保存是明确确认。旧版本自动接受但未审核的记录列在待审核区，保留原 ID、来源与计数，补审前不进入新池。
3. 已启用的内核自动引用符合当前项目、相关性及预算的已审核普通记忆。来源仅用于溯源，不再逐条选择接收内核。不是每轮塞入整个池子。
4. 关闭某内核后停止其后续读取、注入和 DSH 提取任务提交，另一内核和记录不受影响。已发给模型的历史消息不能撤回。

日常界面不再要求操作“旧实例开关 + 模块互通 + 接收方开关”三层设置。历史逐条授权仅保留查看和撤销，不继续创建新的逐条授权。记忆池为统一逻辑视图，原始记录仍留在来源实例物理库，不做搬迁或双份写入。

## 授权与兼容

- 新开关通过 `memory_set_pool_target` 原子写入本壳 `memory-sharing/target-use.json`，同时记录所确认的来源快照。DSH、MiniMax 各自独立；开启一个不会代开另一个。
- 未迁移的旧用户保留旧行为，不自动把单侧许可升级为公共池。界面明确显示旧设置仍在使用时的状态，用户主动确认后采用新池。
- 新池接管后，不再回退到旧逐条或旧实例许可。关闭和来源变化都按停止处理；旧命令的关闭也不能被新池绕过。
- 只有 DSH 时也可使用；新增 MiniMax 会改变来源范围，旧确认不会自动覆盖新来源。
- 损坏或未知版本的目标配置拒绝写入/使用，避免重建文件时误清另一内核选择。来源记录不修改、不丢弃。
- 开启即许可该内核从已审核池引用，并使用已接通的候选提取能力。远端模型接收到的记忆属于模型请求上下文，因此首次确认说明此范围。

## 审核与检索边界

- 公共池只包含 `accepted` 且 `verified` 的普通记忆；候选、停用、删除以及旧未审核记录不参与新池注入。
- 项目记忆仍匹配项目路径；跨内核不复用内核局部 workspace ID。通用偏好可跨项目。
- 召回评分使用原始标题；来源标记在排序后加入显示标题，并计入单条与总注入预算，避免较长请求无法命中标题。
- 自动注入的普通记忆 ID 为 `<namespace>/<id>`，DSH 的 `memory_read` 可用该 ID 读取已授权来源的全文。每次读取重新校验接收方、当前来源范围、已审核状态及项目范围；跨来源只按项目路径匹配，不接受另一内核的局部 workspace ID。使用计数写回真实来源库，响应保留带来源的 ID。裸 ID 仍只读取当前库。
- 审核命令携带来源 namespace，不会把同 ID 的另一侧记录误审；旧记录审核校验 revision，保留来源与计数。
- 自动提取不再调用自动接受入口；相同已审核正文仍可合并来源，不引入新正文。关闭后拒绝排队、领取及迟到提交；`/v1/memory/context?pending=1` 同样返回停用空结果，不向提取调用返回候选内容。记录和候选仍保留，重新启用后可继续读取。
- 本次同时修正动态上下文缓存：开关关闭即使代次不变也清空，删除/停用导致代次变化后的零命中不能继续沿用旧正文。
- 交接和经验仍属于既有 DSH 扩展能力，不纳入跨来源普通记忆池；跨来源全文读取仅限已授权、已审核的普通记忆；完整效果账本不是本次完成范围，按来源注入计数保持不变。

## 接线与未完成项

- DSH 启用开关会检查并自动接入既有本地记忆插件；接入失败不继续写入公共池授权，界面保留原因。若运行中拒绝接入，先停止工作台后重试。关闭记忆开关不会卸载插件。修改内置插件后运行 `npm run prep:builtin`，重新构建并重启壳和工作台；不能用旧插件进程验收新语义。
- MiniMax 使用受管 `UserPromptSubmit` hook 引用公共池，未接线的工作台启用后需要重启。
- **MiniMax 会话自动提取尚未实现**。0.1.7 虽有 Stop hook 和会话路径，但没有已确认受支持的独立无工具模型调用。Stop 输出会续跑正常代理会话，可能执行工具或递归触发，不能冒充后台提取。具体证据和下一步受限执行器方案见 [MiniMax 自动提取缺口](minimax-extraction-gap.md)。MiniMax 手工记录与已有候选可进入来源审核/公共池，不应被描述为自动提取已完成。
- 浏览器模拟只验证 Vue 界面和动作，不等于真实 Tauri 桥、MiniMax hook 或模型请求验收。
