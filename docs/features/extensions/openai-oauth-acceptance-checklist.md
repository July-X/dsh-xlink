# 内嵌 OpenAI OAuth 插件——实机验收清单

日期：2026-10-09。状态：**活文档**——逐项打勾的执行记录随验收轮次更新（每轮记日期与环境）。
依据：[开发计划](openai-oauth-development-plan.md) §10 验收矩阵 + §9 分阶段完成条件；本文把它拆成**可手工执行的步骤**，供有真实环境（实机 / 真实 ChatGPT 账号 / SIWC 端点可达）时逐项执行。

执行环境约定：

- **平台**：Intel macOS 与 Windows 各一轮（§10 要求 6 组结果；macOS 通过不代表 Windows 通过）。
- **内核**：锁定当次发布支持的 3 个版本逐一执行（当前窗口见[开发计划 §1.1](openai-oauth-development-plan.md)）。
- **前置**：`npm run prep:builtin` 已执行（资源清单与源码一致，`check:builtin` 绿）；真实 ChatGPT 账号可用；SIWC 端点可达。
- **红线**：真实令牌与授权回调参数**不进**任何记录、截图或日志文件（设计 §9）；验收产物只保存脱敏结果。

## 2. 登录与账户（每内核版本，需真实账号）

| # | 步骤 | 通过判据 |
| --- | --- | --- |
| 2.1 | 工作台「设置 → 模型」找到 OpenAI 提供方卡 | 卡片在列；账户区显示「未登录」；无命令行参与 |
| 2.2 | 点「登录 ChatGPT」 | 系统浏览器打开授权页（工作台页面内不发生跳转）；工作台卡片进入「登录进行中」 |
| 2.3 | 浏览器完成授权 | 回调页显示「登录完成」；卡片自动翻成已登录 + 脱敏邮箱 |
| 2.4 | 浏览器点拒绝 | 卡片报「授权未完成」；无任何凭据落盘 |
| 2.5 | 浏览器直接关掉（不走回调） | 登录等待超时（180 秒）；可重试；状态回未登录 |
| 2.6 | 退出登录 | 卡片回未登录；系统凭据库条目删除；远端吊销未确认的提示如实显示 |
| 2.7 | 相同邮箱的另一工作区账号分别登录 | 两个注册分别保存，不混用 client_id 与令牌 |

## 3. 模型与强度（每内核版本，需真实账号）

| # | 步骤 | 通过判据 |
| --- | --- | --- |
| 3.1 | 会话选择器查看模型列表 | 只出现当前账号目录的模型（名称、排序与官方一致）；无手工输入冒充 |
| 3.2 | 每个模型逐个检查思考强度控件 | 只出现该模型已验证档位；未验证模型不显示档位 |
| 3.3 | 选择「模型默认」发送 | 请求载荷**不含** reasoning 字段（抓包或桥接日志确认） |
| 3.4 | 选择每个已验证档位发送 | 载荷 `reasoning.effort` 与所选值精确一致 |
| 3.5 | 切到另一模型（旧档位在新模型不存在） | 发送被阻止并提示重新选择；不静默降级 |
| 3.6 | 流式回答中断网 | 已输出文本保留；错误按网络类呈现；成功不被 EOF 伪造 |
| 3.7 | 工具调用往返 | 模型发起工具调用 → 内核执行 → 结果回传 → 最终回答正常；call_id 关联不丢 |
| 3.8 | 重启工作台后继续会话 | 多轮上下文正常；回放材料跨重启保留（思考/工具关联不丢） |

## 4. 网络与故障（每平台一轮）
