关闭 MiniMax 体验入口？

关闭后只隐藏相关入口，不会停止工作台，也不会删除数据或撤销已有授权。

MiniMax 工作台仍在运行，已授权的共享记忆仍可能被使用。取消后可到「概览」停止工作台或到「记忆」管理授权；隐藏后可重新开启体验入口。

记忆授权范围

DeepSeekdsh/default/web

双向普通记忆互通
  • 通用记忆和匹配同一项目的普通记忆可被检索。
  • 交接、经验、候选不因该授权自动互通。
  • 历史逐条授权 1 项；关闭普通记忆互通不会撤销它。
  • 目标开关控制接收方是否使用，不会撤销来源共享授权。
